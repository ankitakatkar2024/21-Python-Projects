
# 📝 Mad Libs Generator

A fun and interactive Mad Libs Generator built using Python.

This project allows users to enter different types of words, such as names, places, adjectives, animals, verbs, and objects. Python combines these words to generate a funny and creative story.

---

## 🚀 Features

- Interactive user input.
- Generates funny and creative stories.
- Uses user-provided words.
- Simple and beginner-friendly interface.
- Option to create multiple stories.
- Menu-free, easy-to-use gameplay.

---

## 🛠️ Technologies Used

- Python 3
- Functions
- Variables
- Strings
- F-Strings
- User Input
- While Loops
- Conditional Statements

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd 06-madlibs-generator
```

### 3. Run the program

```bash
python madlibs_generator.py
```

No external libraries are required.

---

## 🎮 How to Play

1. Run the Python program.
2. Enter the requested words.
3. Provide a name, place, adjective, animal, food, verb, number, emotion, and object.
4. Wait for Python to generate your story.
5. Read your funny story.
6. Choose whether you want to create another story.
