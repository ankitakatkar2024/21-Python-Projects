# Adventure Game

A simple text-based adventure game developed using Python. The player makes decisions at different stages of the story, and each decision leads to a different outcome.

## Features

- Interactive text-based gameplay
- Multiple story paths and endings
- Input validation
- Replay option
- Personalized welcome message

## Technologies Used

- Python 3

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python adventure_game.py
```

- Functions
- Conditional statements
- While loops
- User input and output
- Lists
- String methods
- Return statements
- Main function
