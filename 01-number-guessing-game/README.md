# 🎮 Number Guessing Game

## 📌 About the Project

The Number Guessing Game is a beginner-friendly Python project where the computer generates a random number, and the player tries to guess it.

The player selects a difficulty level and gets a limited number of attempts to find the correct number.

This project is part of my **21 Python Projects Challenge**, where I build one Python project every day to improve my programming skills.

## ✨ Features

- Random number generation.
- Three difficulty levels: Easy, Medium and Hard.
- Limited guessing attempts.
- Hints for guesses that are too high or too low.
- Score calculation based on attempts.
- High scores saved using JSON.
- Input validation and error handling.
- Option to play multiple rounds.
- Game statistics.

## 🛠️ Technologies Used

- Python 3
- Random Module
- JSON Module
- Pathlib Module
