# ✊ Rock Paper Scissors Game

## 📌 About the Project

Rock Paper Scissors is a simple command-line game developed using Python. The player competes against the computer by choosing Rock, Paper, or Scissors.

The computer randomly selects its choice, and the program determines the winner based on the game rules.

This project is part of my **21 Python Projects Challenge**, where I build one Python project every day to improve my programming and problem-solving skills.

## ✨ Features

- Player vs Computer gameplay.
- Random computer selection.
- Win, lose and draw detection.
- Input validation.
- Real-time scoreboard.
- Total rounds tracking.
- Win percentage calculation.
- Final match statistics.
- Replay functionality.
- Quit option.

## 🛠️ Technologies Used

- Random Module

## 🎮 Game Rules

| Player Choice | Computer Choice | Result |
|---|---|---|
| Rock | Scissors | Player Wins |
| Paper | Rock | Player Wins |
| Scissors | Paper | Player Wins |
| Rock | Rock | Draw |
| Paper | Paper | Draw |
| Scissors | Scissors | Draw |
